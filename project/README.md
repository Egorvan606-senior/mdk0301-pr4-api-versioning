# ПР4 — версионирование API

Исходники восстановлены из листингов отчёта ПР4. В исходном отчёте отсутствовал листинг `Models/ProductStore.cs`: три товара и их цены восстановлены по реальным снимкам Swagger UI; численные остатки на складе условные и дают тот же признак `inStock`. Данные демонстрационные.

```powershell
dotnet restore
dotnet run --urls http://localhost:5180
```

Откройте `ApiVersioningLab.Ivanov.slnx` в Visual Studio и запустите проект. В файле `ApiVersioningLab.Ivanov.http` доступны запросы к обоим версиям API. Документация: `http://localhost:5180/swagger`.

Для автоматической проверки после сборки выполните `python verify_api.py`: скрипт запускает локальный сервер на свободном порту и проверяет оба контракта, три товара, поиск по `id`, ответ `404` и документы Swagger.
